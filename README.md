# Django E-Commerce Store

A full-stack e-commerce web application built with Django. Users can browse products by category, register/login, add items to a cart, checkout, and track orders. Includes an admin panel for managing products and orders.

## Features

- **Product catalog** with categories: Electronics, Fashion, Perfumes, Home Accessories
- **User authentication** — register, login, logout
- **Shopping cart & checkout** flow
- **Order tracking** with customer name, email, and address
- **Admin panel** for managing products and orders
- **Bulk product loader** script (`load_products.py`) to seed the database

## Tech Stack

- **Backend:** Python, Django
- **Database:** SQLite
- **Frontend:** HTML, CSS (Django templates)
